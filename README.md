# Луна — ИИ-психолог в Telegram (лендинг)

Статический hero-блок лендинга. Адаптив от десктопа до 360px. Без сборки — чистый HTML/CSS.

## Структура

```
luna-landing/
├── index.html          # страница целиком (стили внутри)
├── assets/
│   ├── girl.png        # фото Луны (прозрачный PNG)
│   ├── glow.svg        # размытое свечение за фото
│   └── chat.png        # мокап переписки в Telegram
├── .nojekyll           # чтобы GitHub Pages отдавал файлы как есть
└── README.md
```

## Локальный просмотр

Просто открой `index.html` в браузере (двойной клик) — картинки подтянутся.
Либо подними локальный сервер:

```bash
python3 -m http.server 8753
```

и открой http://localhost:8753/

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/root`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
