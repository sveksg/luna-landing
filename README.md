# Луна — ИИ-психолог в Telegram (лендинг)

Одностраничный лендинг из 5 блоков. Адаптив от десктопа (макет 1440) до 360px. Без сборки — чистый HTML/CSS/JS, всё в одном файле `index.html`.

## Структура

Все файлы лежат в одной папке (плоско, без подпапок) — удобно загружать на GitHub.

```
luna-landing/
├── index.html            # весь лендинг (5 блоков) + шапка + футер, стили/скрипты внутри
├── favicon.png, favicon-32.png
├── girl.png, chat.png    # блок 1
├── img2.jpg, notes.svg, logos_telegram.svg   # блок 2
├── luna-avatar.png, chatgpt.svg, 1.png…4.png, bg.svg   # блок 3
├── spiral.svg            # блок 4
├── avatar.png, phone-screen.jpg   # блок 5
├── .nojekyll
└── README.md
```

## Блоки

1. Hero — «ИИ-психолог в Telegram…» + фото + чат.
2. «Выбери, что близко» — чекбоксы с динамичной цитатой.
3. Сравнение с ChatGPT + «Создана, чтобы быть под рукой» (маскоты, анимации).
4. «За каждым ответом Луны» — карточки + спирали с параллаксом по скроллу.
5. Тарифы + финальный CTA (телефон и аватар).

## Локальный просмотр

```bash
python3 -m http.server 8753
```

и открой http://localhost:8753/

## Публикация на GitHub Pages

1. Залей содержимое папки в репозиторий (вместе со всеми папками ассетов).
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
3. Сайт откроется по `https://<username>.github.io/<repo>/`.
